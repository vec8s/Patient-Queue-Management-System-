## 1. نظرة عامة على المشروع وأهدافه
صُمم نظام **Patient Queue Management System** ليحل مشكلة الازدحام وتشتت المراجعين في المنشآت الصحية، حيث يقوم بأتمتة رحلة المريض كاملة منذ وصوله للمركز وحتى دخوله لغرفة الطبيب وخروجه:
* **خدمة ذاتية للمريض**: تسجيل حضور فوري، حجز مواعيد مسبقة، استخراج رقم تذكرة طابور تلقائي.
* **شاشة انتظار حية وتفاعلية (Live TV Queue)**: عرض رقم المريض الحالي، اسم الطبيب، ورقم الغرفة مع مناداة تنبيهية فورية وتحديث دوري كل بضع ثوانٍ.
* **مساحة عمل الطبيب والكادر الطبي (Doctor Workspace)**: مناداة المريض القادم بضغطة زر وتحديد غرفة الكشف وإنهاء الاستشارة.
* **لوحة إدارة النظام (Admin Panel)**: مراقبة إحصائيات الحضور اليومية وإدارة طاقم العمل.

## 2. البنية المعمارية والتقنيات المستخدمة
يعتمد النظام على هيكلية معمارية واضحة ومبسطة تضمن سهولة القراءة وسرعة الاستجابة دون أي تعقيدات زائدة:

* **الواجهة الخلفية (Backend)**:
  * لغة **PHP** (متوافقة مع إصدارات PHP 7.4 وحتى PHP 8.3+).
  * خدمات برمجية مبنية بنمط RESTful API تعيد البيانات بصيغة JSON.
* **قواعد البيانات (Database)**:
  * **MySQL / MariaDB** بمحرك InnoDB لضمان العلاقات والقيود التلقائية (`Foreign Keys`) وترميز `utf8mb4` لدعم كافة اللغات.
* **الأمان والمصادقة (Security & Authentication)**:
  * تشفير كلمات المرور باستخدام المعيار الآمن `PASSWORD_DEFAULT` (Bcrypt).
  * إدارة الجلسات عبر تقنية **JWT (JSON Web Tokens)** عبر مكتبة `firebase/php-jwt`.
  * حماية الاستعلامات ضد هجمات الـ SQL Injection عبر الاستعلامات المجهزة (`Prepared Statements`).
* **الواجهة الأمامية (Frontend)**:
  * **HTML5** & **CSS3** متجاوبة بالكامل مع مختلف الشاشات (الهواتف، الأجهزة اللوحية، والشاشات الجدارية).
  * إطار التنسيق **Bootstrap 5.3** مع أيقونات **Bootstrap Icons**.
  * **Vanilla JavaScript** خفيف وسريع للتواصل مع الـ APIs والتحكم في التحديث اللحظي لشاشة الانتظار.

## 3. شرح ملفات المشروع ومجلداته بالتفصيل نقطة بنقطة

### أ. صفحات واجهة المستخدم الرئيسية (Root Pages)
1. **`index.php` (الصفحة الرئيسية)**:
   * نقطة الدخول الترحيبية للجمهور والموظفين.
   * تحتوي على مدخل لتسجيل الحضور، حجز المواعيد، شاشة الانتظار، وبوابة الكادر الطبي.
2. **`visit.php` (بوابة بدء الزيارة)**:
   * تسأل المراجع عما إذا كانت هذه زيارته الأولى للمركز أو سبق له التسجيل، لتوجيهه للمسار الصحيح.
3. **`registration.php` (تسجيل مريض جديد)**:
   * نموذج لإدخال بيانات المريض الجديد (الاسم، تاريخ الميلاد، الجنس، الهاتف، المنطقة السكنية، الموافقة على الخصوصية).
   * بعد الحفظ، يحصل المريض مباشرة على خيار استخراج تذكرة الدخول.
4. **`patient-search.php` (البحث الآمن عن مريض)**:
   * يتيح للمريض السابق أو موظف الاستقبال البحث عن ملف المريض بالاسم أو رقم الهاتف لاستكمال تسجيل الحضور دون إدخال البيانات مجدداً.
5. **`checkin.php` (تسجيل الحضور وإصدار التذكرة)**:
   * يحتوي على مسارين:
     * مسار حاملي المواعيد: إدخال كود الموعد المسبق والحصول على رقم مثل `APPT-001`.
     * مسار المراجعين الفوريين (Walk-In): تحديد سبب الزيارة والحصول على رقم مثل `WALK-001`.
   * يظهر للمريض نافذة تأكيد برقم تذكرته وتوجيهه لشاشة الانتظار.
6. **`appointments.php` (حجز موعد مسبق)**:
   * صفحة لحجز استشارة مستقبلية: اختيار الطبيب، نوع الخدمة، التاريخ، والفترة الزمنية.
   * يصدر النظام كود موعد مميز (مثل `APT20260912001`) لاستخدامه يوم الحضور.
7. **`queue.php` (شاشة صالة الانتظار - Live Display)**:
   * واجهة مصممة خصيصاً لشاشات التلفزيون في غرف الانتظار.
   * مقسمة إلى قسمين رئيسيين:
     * **القسم الأكبر (Now Serving)**: يعرض رقم المريض الحالي المستدعى، اسمه، اسم الطبيب، ورقم الغرفة.
     * **القسم الجانبي (Next in Queue)**: يعرض قائمة المرضى القادمين في الطابور مع أوقاتهم.
   * تعمل بتحديث تلقائي حي ومستمر عبر تقنية Polling دون الحاجة لتحديث الصفحة.
8. **`dashboard.php` (لوحة تحكم الأطباء والكادر)**:
   * تتيح للطبيب الاطلاع على قائمة الانتظار الحالية، الحالات الجارية، والحالات المنتهية.
   * تتضمن نافذة مناداة المريض القادم (`Call Next Patient`) لاختيار الغرفة واستدعاء المريض.
9. **`admin.php` (لوحة الإدارة العامة)**:
   * عرض مؤشرات وإحصائيات المركز: إجمالي المرضى المسجلين، حضور اليوم، وعدد الكادر النشط.
   * جدول إدارة الموظفين والأطباء المسجلين وتاريخ انضمامهم.
10. **`login.php` (بوابة الكادر الطبي)**:
    * تتيح تسجيل الدخول للأطباء والموظفين بالبريد وكلمة المرور وتوليد توكن JWT.
    * تتيح تبويب لإنشاء حساب موظف جديد وتحديد دوره (طبيب، ممرض، موظف استقبال، مدير).

### ب. مجلد القوالب والمكونات المشتركة (`includes/`)
تم إنشاء هذا المجلد لتبسيط الكود ومنع تكراره في الصفحات:
1. **`includes/header.php`**:
   * يحتوي على وسوم الـ HTML والـ Meta وتنسيقات Bootstrap و Icons واستيراد الأنماط.
   * يضبط عنوان الصفحة تلقائياً وفق ثوابت النظام الموحدة.
2. **`includes/navbar.php`**:
   * شريط التنقل العلوي الموحد، يحمل اسم النظام الجديد، ويوفر روابط دقيقة لكل الصفحات (`.php`) مع إظهار اسم الطبيب وزر الخروج إذا كان مسجلاً.
3. **`includes/footer.php`**:
   * تذييل الصفحات المشترك وحقوق الملكية واستدعاء مكتبات الـ JavaScript.

---

### ج. مجلد العمليات والواجهات البرمجية (`php/`)
1. **`php/config.php`**:
   * ملف الإعدادات المركزي، يحتوي على:
     * اسم النظام: `Patient Queue Management System`.
     * بيانات الاتصال بقاعدة البيانات.
     * المفتاح السري لتشفير الـ JWT وخيارات انتهاء الصلاحية.
2. **`php/db_connect.php`**:
   * تأسيس الاتصال الآمن بقاعدة البيانات باستخدام `mysqli`.
   * دالة `executeQuery($query, $params, $returnInsertId)` المجهزة لتنفيذ الاستعلامات الآمنة مع تفادي ثغرات الحقن عبر ربط المتغيرات (`Prepared Statements`).
3. **`php/auth.php`**:
   * توحيد منطق المصادقة: توليد توكن JWT، التحقق من صحته وفك تشفيره، وقراءة هيدر المصادقة القياسي (`Bearer <token>`).
4. **`php/migration.php`**:
   * سكربت تهيئة الجداول وحقن البيانات الافتراضية. يعمل بشكل مستقل عند تثبيت النظام لأول مرة دون أن يثقل كاهل الصفحات الأخرى في كل زيارة.
5. **`php/api_register_staff.php`**:
   * استقبال طلبات تسجيل الدخول والتحقق من كلمات المرور عبر `password_verify`، واستقبال تسجيل الموظفين الجدد بأمان.
6. **`php/api_register_patient.php`**:
   * إضافة مريض جديد لقاعدة البيانات، والبحث عن المرضى بالاسم أو الهاتف لإرجاع نتائج آمنة.
7. **`php/api_patient_checkin.php`**:
   * معالجة حضور المريض (بموعد أو بدون موعد)، توليد أرقام التذاكر الفريدة (`APPT-xxx` / `WALK-xxx`)، وتحديث حالة المريض عند استدعائه لغرفة الكشف.
8. **`php/api_patient_schedule.php`**:
   * حجز موعد جديد في قاعدة البيانات، وإرجاع الحالة اللحظية لطابور اليوم (المنتظرون، قيد الكشف، والمكتملون).
9. **`php/api_token_manager.php`**:
   * التحقق السريع من صلاحية توكن المستخدم المتواجد في المتصفح.

---

### د. مجلد ملفات الـ JavaScript والأنماط (`js/` & `css/`)
1. **`js/script.js`**:
   * **إدارة التنبيهات**: دالة `showAlert(type, message)` لتقديم تنبيهات أنيقة للمستخدم تختفي تلقائياً.
   * **التحديث اللحظي (Live Polling)**: تحديث بيانات شاشة الانتظار كل 5 ثوانٍ تلقائياً من الـ API.
   * **التنبيه الصوتي (Chime)**: تشغيل نغمة تنبيه لطيفة باستخدام Web Audio API عند مناداة مريض جديد.
   * **إدارة الجلسة**: التحقق من تسجيل دخول الطبيب والتعامل مع زر تسجيل الخروج.
2. **`css/style.css`**:
   * التنسيقات العامة للبطاقات، شاشات الانتظار، الخطوط، وأزرار التنقل.

## 4. جداول قاعدة البيانات ومخطط العلاقات

| اسم الجدول | الوظيفة | الحقول الرئيسية |
| :--- | :--- | :--- |
| **`staff`** | حسابات الأطباء والموظفين والإداريين | `id`, `first_name`, `last_name`, `email`, `password` (مشفرة), `role`, `is_active` |
| **`patients`** | السجل الطبي الأساسي لكل مريض | `id`, `first_name`, `last_name`, `date_of_birth`, `gender`, `phone`, `address` |
| **`checkin_types`** | أنواع تسجيل الحضور | `id` (1=موعد مسبق, 2=حضور فوري), `type_name` |
| **`appointment_types`** | أقسام وخدمات العيادة | `id`, `name` (استشارة عامة، تطعيم، طوارئ..), `duration` (المدة بالدقائق) |
| **`rooms`** | غرف الكشف المتاحة | `id`, `name` (Room 1, Room 2...), `description` |
| **`checkins`** | سجلات الزيارات والمواعيد | `checkin_id`, `patient_id`, `type_id`, `doctor_id`, `reference_number`, `status` |
| **`queue`** | طابور الانتظار اليومي الفعلي | `id`, `checkin_id`, `queue_number`, `status` (`waiting`, `in_progress`, `completed`), `called_by`, `room_id`, `called_at` |

## 6. الإصلاحات والتحسينات الأمنية المنفذة

1. **توحيد اسم وهوية النظام**: تم تغيير كافة الإشارات من الأسماء التجريبية السابقة إلى الاسم الرسمي: **Patient Queue Management System**.
2. **سد ثغرات الـ SQL Injection**: تحويل كافة الاستعلامات البرمجية لتعتمد على المعاملات المجهزة (`Prepared Statements`) لمنع أي تلاعب بقاعدة البيانات.
3. **حماية خصوصية بيانات المرضى**: إيقاف تصدير قاعدة بيانات المرضى إلى كود الـ JavaScript في المتصفح في صفحة البحث، وجعل البحث استعلامياً آمناً وسريعاً عبر الـ API.
4. **تصحيح الروابط المكسورة**: تعديل جميع الروابط القديمة التي كانت تشير إلى صفحات `.html` مفقودة لتشير مباشرة إلى ملفات `.php` الصحيحة.
5. **تسريع أداء الموقع**: فصل تشغيل ملف `migration.php` ليعمل لمرة واحدة فقط عند الإعداد، بدلاً من إعادة فحص الجداول وبنائها في كل زيارة لأي صفحة.
6. **دعم التحديث الحي والتنبيه الصوتي لشاشة الانتظار**: ربط شاشة العرض باستعلام دوري خفيف يصدر نغمة تنبيه عند دخول دور المريض.

## 7. دليل التثبيت والتشغيل خطوة بخطوة

### الخطوة 1: المتطلبات الأساسية
* بيئة خادم محلي مثل **XAMPP** أو **WAMP** أو **Laragon** تدعم:
  * PHP 7.4 أو أحدث (يوصى بـ PHP 8.1 أو 8.2).
  * خادم قواعد بيانات MySQL أو MariaDB.

### الخطوة 2: وضع المشروع في مسار السيرفر
انسخ مجلد المشروع بالكامل إلى مجلد الويب:
* في XAMPP: داخل المجلد `htdocs/pqms`
* في WAMP: داخل المجلد `www/pqms`

### الخطوة 3: ضبط الاتصال بقاعدة البيانات
افتح الملف `php/config.php` وتأكد من مطابقة بيانات قاعدة بياناتك المحلية:
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'db_pqms');
```

### الخطوة 4: تشغيل التهيئة التلقائية (Migration)
افتح المتصفح وتوجه إلى الرابط التالي لتجهيز قاعدة البيانات والجداول تلقائياً وبضغطة زر:
```
http://localhost/pqms/php/migration.php
```
ستظهر لك رسالة نجاح التهيئة وتوليد الجداول والبيانات الافتراضية.

### الخطوة 5: بدء استخدام النظام
افتح الرابط الرئيسي:
```
http://localhost/pqms/
```
